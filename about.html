MY STORY

The Path of a Builder & Researcher

My journey into computing started with a simple question: How can software automate complex, repetitive tasks while remaining resilient against adversarial abuse?

As a Computer Science student and researcher, I dive deep into the foundations of computer systems. Rather than staying in purely academic theory, I believe in building tangible tools. This curiosity led me to develop high-throughput automated bots using Python and Pyrogram MTProto, implement relational databases with PostgreSQL, and write full-stack applications in TypeScript.

My work centers around four pillars: Python for expressive and async-driven backend services, Artificial Intelligence for smart query resolution and automation, Cyber Security for hardened access control and antispam defenses, and PostgreSQL for structured, reliable data persistence.
